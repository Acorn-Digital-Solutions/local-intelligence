From your terminal

curl http://compute.local/ollama/api/tags        # models as JSON
curl http://compute.local/logs/ollama | tail -5  # recent server activity
opencode run -m ollama/qwen3.8:27b-mlx "add retry logic"  # terminal agent
opencode models ollama                           # check provider wiring

Clients on other machines

Point Continue and opencode at http://compute.local:11434 (or the no-port http://compute.local/ollama/v1 baseURL), MCP tools at http://compute.local:8012/mcp. The repo's client-setup.sh automates this. Full setup and model guide: README.
